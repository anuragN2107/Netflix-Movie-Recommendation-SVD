## 📊 Dataset Description
The dataset used in this project is too large to host directly on GitHub. You can download the raw files here:
👉 **[Download Dataset from Google Drive](https://drive.google.com/drive/folders/1T4kugstkoC8PJIRq9FCtIpHdlySXjpvG?usp=sharing)**

[cite_start]The data consists of two key components[cite: 64]:
* [cite_start]**Ratings Dataset (`combined.txt`):** Over 24,058,263 rows containing `Customer ID`, `Ratings` (1-5 stars), and `Movie ID`[cite: 65, 68, 69, 70, 71].
* [cite_start]**Movie Metadata (`movie_titles.csv`):** 17,770 rows detailing `Movie ID`, `Movie Name`, and `Year of Release`[cite: 49, 77, 78, 79, 80].
